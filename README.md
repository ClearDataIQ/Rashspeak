# RashSpeak Studio 2.7 WIP

**[تنزيل المصدر المحدّث — ZIP](https://raw.githubusercontent.com/ClearDataIQ/Rashspeak/main/RashSpeak_Studio_2.7_WIP.zip)** · [دليل التشغيل والقيود](DAILY_PRODUCTION_2.7_AR.md) · [التغييرات](CHANGELOG_2.7_WIP_AR.md) · [حالة التحقق](RELEASE_STATUS_2.7_WIP.json)

تحديث فعلي للمصدر المحلي2.6.8 على جهاز المالك Windows11 وRTX4060، مع
حفظ تاريخ Git وملفات الوسائط والمشاريع السابقة. أُصلح فصل مفاتيح Google
وOpenRouter والعناوين، واختبارات النص والصورة والفيديو، والتوقف المحفوظ
عند نفاد الحصة، واستئناف الصوت دون تكرار المعالجة، ومشروع Auto/Pro المشترك،
وتخطيط أزرار الواجهة وقراءة العربية على Windows.

اجتاز المصدر **383 اختبارًا دون فشل أو تخطٍ**. التفريغ المحلي CUDA نجح
فعليًا على التسجيل الكامل673.36ث خلال54.01ث؛ هذا اختبار تشغيل وليس تقييم
دقة بشريًا. NVENC1080p اجتاز رندرًا تقنيًا بنمط اصطناعي معلن، وليس حلقة.
Google gemini-3.1-flash-lite نجح فعليًا في اختبارات نص12جملة وصورة وفيديو
مع JSON، ثم أعاد طلب فهم التسجيل429. OpenRouter مضاف واختُبر بمحاكاة
معلنة فقط؛ لم يُتحقق حسابه الحي. لا تبديل تلقائي إلى خدمة مدفوعة.

**قبول الإنتاج اليومي لم يكتمل:** المسار الحقيقي للعينة بلا سكربت، وبسكربت
اختبار مشتق ومعلن من التفريغ، ثم التسجيل الكامل، حفظ مسودة needs_media.
التغطية المتحقق منها0% والأرشيف خالٍ من الأصول المعتمدة. لا حلقة أو
شورت جديد مجتاز. لا يُعد نجاح الوحدات أو اختبارات API إثبات جودة المشاهد.
يلزم تجدد حصة الفهم ولقطات حقيقية مطابقة مع تصريح استخدام موثق، ثم
مراجعة الصوت والترجمة واختبار المسار النهائي. لا يُختلق إذن ولا يُخفض
حد التغطية لإجبار التصدير. الفيديوهات القديمة محفوظة كسجل وليست قبولًا
للجودة المطلوبة.

## التشغيل والتحديث

فك المصدر وشغّل START_WINDOWS.bat؛ يلزم Python3.11+ مع Tk وFFmpeg/ffprobe.
يوجد تثبيت محلي للاعتماديات والتفريغ، وINSTALL_CUDA_WINDOWS.bat اختياري
لمكتبات CUDA داخل .venv. CPU بديل. النموذج الصوتي تنزيل منفصل؛ لا LLM
أو نموذج رؤية ضخم. لا EXE مستقل مبني أو موقّع في هذه الحزمة.

عند التحديث احتفظ بنسخة استعادة، وأغلق الأداة، واستبدل ملفات المصدر فقط.
احتفظ بـoutput وmodels و.venv ومفاتيح خزنة النظام. الحزمة لا تضم تسجيلات
أو مشاريع خاصة أو إعدادات مفاتيح أو نماذج. النسخة المستخرجة اشتغلت على
الجهاز باستخدام بيئة Python المحلية الموجودة؛ فُتح Auto Studio وإعدادات
المزوّد وPro Editor على مسودة التسجيل. دورة إنتاج بشرية كاملة من الواجهة
ما زالت غير مجتازة. المصدر يحفظ مراجعات المراحل للاستخدام الطبيعي.
