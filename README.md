# RashSpeak Studio 2.6.6 WIP

**[تنزيل حزمة المصدر المحدّثة — ZIP](https://raw.githubusercontent.com/ClearDataIQ/Rashspeak/main/RashSpeak_Studio_2.6.6_WIP.zip)** · [التغييرات](CHANGELOG_2.6.6_WIP_AR.md) · [الاختبارات](TEST_RESULTS_2.6.6_WIP.txt) · [SHA256](RashSpeak_Studio_2.6.6_WIP_SHA256.txt)

التقرير الأخير أظهر Gemini HTTP 400، ومصادر تحتاج تصريحًا، وخطأ هوية Steam. يوضح التحديث نوع رفض الطلب بدل رسالة واحدة عامة. عند رفض بنية الاستجابة صراحة توجد محاولة توافق محدودة بنفس النموذج والمدخلات، مع إبقاء مدققات التوقيت والهوية والحقوق. لا تعاد المحاولات لرفض المفتاح أو الحساب أو خطأ غير معروف.

في **مفاتيح YouTube وGemini → Gemini** أضفنا **اختبار تحليل فعلي** بنص تجريبي قصير وبنية الإنتاج؛ نجاح قائمة النماذج وحده لا يختبر التحليل. لا يُرسل التسجيل أو المشروع، ويستهلك الزر طلب API عند الضغط. احفظ الإعداد، ثم ارجع إلى **أعد تحليل السياق وتركيب اللقطات** داخل مراجعة اللقطات. [الخطوات وأنواع الأخطاء وحدود التحقق](GEMINI_REQUEST_REPAIR_2.6.6_AR.md).

Steam يقبل اختلاف رمز العلامة التجارية فقط، مع تطابق رقم التطبيق والنوع والاسم الكامل. نقص بيانات المتجر مستقل عن هوية لعبة أخرى وعن رفض الشبكة. المصادر المنتظرة ما زالت تحتاج إذن الاستخدام والتنزيل ومشهدًا مطابقًا؛ لا يُفترض ترخيص فيديو لأنه عام.

## التحقق والتشغيل

اجتاز المصدر **346 اختبارًا** دون فشل أو تخطٍ، بما فيها Tk وFFmpeg و18 اختبارًا جديدًا للتشخيص والتوافق والتحقق والواجهة. أُعيدت الاختبارات الـ18 بعد آخر إضافة لتصنيف رفض وضع JSON ونجحت؛ ليست 18 اختبارًا فريدًا إضافيًا. فُتح Auto Studio وPro Editor من الحزمة المستخرجة، وفُحص CRC وبصمات الملفات الـ206. لم يتوفر مفتاح للتطبيق في السحابة لاختبار سبب 400 الحي، ولم يحدث تنزيل Steam حي أو فيديو نهائي جديد. القبول التلقائي الكامل ما زال غير مجتاز؛ Windows/RTX4060/EXE غير مختبرة هنا.

يحتاج المصدر Python 3.11+ مع Tk وFFmpeg/ffprobe. لأول تشغيل فك ZIP وشغّل START_WINDOWS.bat. لتحديث أداة موجودة: أغلقها واحتفظ بنسخة من المصدر القديم، ثم استبدل ملفات البرنامج بمحتويات مجلد الحزمة. **احتفظ بـoutput وmodels والأرشيف**. الحزمة لا تضم مفاتيح أو تسجيلات أو وسائط أو نماذج أو FFmpeg.

إصلاحات الصوت والعربية ومراجعة اللقطات في 2.6.5 محفوظة: [الصوت والعربية](AUDIO_ARABIC_REPAIR_2.6.5_AR.md)، [المصادر والتصاريح](MEDIA_REVIEW_RECOVERY_AR.md). الشورتات 25–60 ثانية، دون توليد صور/فيديو بالذكاء الاصطناعي أو موسيقى تلقائية، والنشر يدوي.

## API مجاني بديل

أُلغي اقتراح نموذج رؤية محلي وفق طلب المالك. OpenRouter مرشح مع نموذج مجاني يدعم الرؤية وJSON بعد التحقق من القائمة والحصة والشروط. **موصل OpenRouter غير مضاف في هذا الإصدار**؛ الربط الحالي Gemini. فشل فحص القائمة الحية على مستوى شبكة السحابة قبل المصادقة، لذلك لا نثبت نموذجًا أو حصة مجانية متغيرة ولا أفضلية دائمة على Gemini. لم يُنزّل نموذج جديد.
