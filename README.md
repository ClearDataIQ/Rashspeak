هذه حزمة المصدر الأحدث لـ Auto Studio وPro Editor. تشمل السكربت الاختياري، إصلاح تقسيم الترجمة العربية وتوقيتها وخطها وحافتها، تطابق المعاينة والتصدير، فحص جودة الصور والفيديو ومطابقة المشاهد، والصورة البديلة القصيرة والأرشيف المشترك. يحتوي المحرر على مسارات حقيقية وتحكم يدوي وثلاث طبقات Overlay للميمز وGIF.

اجتاز الكود **281 اختبارًا** دون فشل أو تخطٍ. جميع ملفات الكود والاعتماديات مطابقة للنسخة المجتازة للاختبارات. فُحصت سلامة ZIP وبصمات المصدر، وفُتحت الواجهتان من الحزمة المستخرجة. الحزمة لا تضم مفاتيح أو تسجيلات أو نماذج أو مكتبة وسائط.

## التشغيل

1. فك ZIP في مجلد جديد، ثم افتح مجلد `RashSpeak_Studio_2.6.3_WIP` وشغّل `START_WINDOWS.bat`. يحتاج Python 3.11+ مع Tk.
2. ضع FFmpeg وffprobe في `tools` أو PATH؛ للتفريغ المحلي ثبّت `INSTALL_ARABIC_SUBTITLES.bat` وجهز النموذج من إعدادات البرنامج. اقرأ `README_AR.md` داخل الحزمة للتفاصيل.
3. من زر **مفاتيح YouTube وGemini** أضف مفاتيحك واختبر كل خدمة. يمكن التحرير المحلي في Pro Editor دون مفاتيح. السكربت اختياري.

Windows وRTX4060 وبناء EXE لم تُختبر في بيئة Linux الحالية؛ هذه حزمة مصدر قابلة للتشغيل باعتمادياتها.
